# dropshipping-bot

Prywatna aplikacja do obsługi jednego, własnego konta sprzedawcy na Allegro.

Do czego służy:
- wyszukuje oferty na Allegro, żeby porównać ceny i konkurencję dla wybranych produktów,
- pobiera kategorie, parametry i podgląd prowizji,
- wystawia oferty na własnym koncie i odczytuje zamówienia na te oferty.

Aplikacja nie jest udostępniana innym sprzedawcom. Kontakt: przez zgłoszenia (Issues) w tym repozytorium.# dropshipping-bot
